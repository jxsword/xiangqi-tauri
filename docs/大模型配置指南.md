# 大模型配置指南

本应用的大模型引擎兼容 **OpenAI Chat Completions 协议**，任何提供该协议的服务均可接入（OpenAI、DeepSeek、豆包/火山方舟、通义千问、Kimi、智谱等）。

## 1. 在哪里配置

- 应用内：主界面 → 设置（齿轮）→ "大模型" 页签
- 字段说明：

| 字段 | 示例 | 说明 |
|---|---|---|
| Base URL | `https://api.deepseek.com/v1` | 服务商 API 根地址（不含 `/chat/completions`，应用自动拼接） |
| API Key | `sk-xxxxxxxx` | 服务商控制台创建的密钥，仅存本机，不回显 |
| 模型 | `deepseek-chat` | 服务商支持的模型名 |
| 超时（秒） | `10` | 超过该时长未返回即降级内置引擎（默认 10） |

## 2. 常见服务商参考

> 请以各服务商最新官方文档为准；此处仅为常见示例，方便快速填写。

| 服务商 | Base URL | 模型示例 | 获取 Key |
|---|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` | platform.deepseek.com |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` | platform.openai.com |

| Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` | platform.moonshot.cn |

## 3. 工作原理（建议了解）

1. 轮到"大模型引擎"走子时，应用将当前局面编码为 **FEN** 并构造提示词（含规则约束："仅输出一步 UCCI 走法，如 h2e2"）。
2. 请求 `POST {base_url}/chat/completions`（Bearer 认证），等待响应。
3. 解析模型输出 → 提取走法 → **与全部合法走法比对**。
4. 输出非法：重试 1 次；仍非法、或超时、网络错误 → **自动降级为内置引擎**走子，并在界面提示原因。
5. 因此：**无论模型回答什么，应用永远不会走出非法着**。

## 4. 安全与隐私

- API Key 仅存储在本机应用数据目录（`app_data_dir/xiangqi/settings.json`），不会写入对局存档、不会上传。
- 每次走子仅发送当前 FEN 与简短提示词，不发送其他个人数据。
- 请在可信设备上使用；妥善保管密钥。
