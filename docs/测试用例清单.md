# 用户测试用例清单（人工验收）

> 用途：自动化测试（`cargo test` + `npm run test` + 机器对弈冒烟）全绿后，由用户在目标平台人工执行本清单。
> 级别：**P0** = 核心功能必须通过；**P1** = 体验增强建议通过。
> 平台列：`Win` = Windows、`mac` = macOS、`Lin` = Linux、`And` = Android。未标记平台 = 全部平台适用。
> 填表：每行记录 通过/失败/备注。
